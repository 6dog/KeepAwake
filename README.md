# Keep Awake

原生 macOS 菜单栏工具：显示 Logitech 鼠标电量，控制防休眠，并在使用实体外接显示器时关闭内置屏幕。

## 控制面板

左键点击菜单栏显示器图标打开面板；面板底部提供退出按钮，右键不再打开菜单。电量数字继续显示在小显示器图标内部，面板顶部只显示单行电量与刷新按钮。

电源模式三选一：

| 模式 | 本程序的行为 |
| --- | --- |
| 跟随系统 | 释放本程序的防休眠断言；是否真的睡眠仍取决于系统和其他应用 |
| 仅防休眠 | 阻止电脑闲置睡眠，允许屏幕自动熄灭 |
| 屏幕常亮 | 保持当前启用的屏幕亮起，同时阻止电脑闲置睡眠 |

“外接时关闭内屏”打开后，实体外接屏可用约 2 秒后关闭内屏。关闭此开关恢复内屏。以前的“保持内屏开启”选项已移除；若升级前启用了该选项，会迁移成自动关闭内屏关闭，保留原有意图。旧电源偏好也会迁移为对应模式。

面板在启动时提前布局，按下图标立即响应，关闭弹出动画；显式处理再次点击图标、点击外部、失去激活和 Escape，避免自动关闭与鼠标松开事件冲突。日志记录真实显示回调和点击到显示耗时。面板使用系统原生 Popover、分段选择、开关和按钮；macOS 26+ 采用系统提供的 Liquid Glass 外观，较旧系统使用原生标准样式。外观跟随系统深浅色、强调色和辅助功能设置，不绘制固定的玻璃渐变或高光。展开长错误时可滚动。点击外部或按 Escape 收起面板。

## 内屏控制与恢复

使用时保持笔记本开盖；Apple Silicon Mac 合盖会在硬件上切断内置麦克风。本程序不切换录音设备，不申请麦克风权限。

- 只有可用的实体外接屏才触发自动关闭；AirPlay、Sidecar、虚拟设备和无法确认的设备不会触发。
- 关闭后最多等待约 3 秒验证；临时失败会先恢复，再按 5、10、20、40、60 秒的间隔自动重试。
- 15 秒内连续三次被系统重新启用时短暂限速，然后自动重试，不会永久暂停。
- 自动关闭内屏期间保持实体外接屏为主屏；多外屏时优先保留当前外接主屏，再使用记住的外接屏。切换主屏时整体平移桌面坐标，保持各屏相对位置。日志记录主屏标记和屏幕坐标。
- 外接屏仍在线但暂时不活跃（例如屏幕休眠）时，不当作拔线恢复内屏；只有可用且活跃的外接屏才允许关闭内屏。
- 失去所有已连接实体外接屏时优先恢复内屏。关闭前保存已确认的内屏 ID；若拔线后内屏也从 SkyLight 列表消失，则使用本次系统启动内保存的 ID 恢复，重启系统后不会复用旧 ID。正常退出先异步恢复，失败则取消退出并保留操作入口。
- 异常结束后下次启动先恢复，再应用自动规则。屏幕配置只作用于当前登录会话；窗口位置不保证还原。
- 屏幕控制使用运行时加载的私有 SkyLight/CoreDisplay 接口，系统升级可能需要适配；缺少接口会显示原因，不影响其他功能。

如果恢复失败，可关闭自动关闭开关重试，或重新开合上盖、拔插外接屏；必要时注销或重启。App 崩溃期间不能保证即时恢复。功耗收益未经测量。

## 自动日志与诊断导出

日志默认在后台自动记录，面板没有诊断按钮或常驻日志状态。日志保存在 `~/Library/Logs/KeepAwake`，不会自动上传。

右键维护菜单已移除；退出时仍会先恢复内屏，再释放防休眠状态。现有登录启动设置保持不变。

日志路径：`~/Library/Logs/KeepAwake/`。常规日志记录操作、状态变化、错误和每分钟摘要；详细模式补充已有屏幕检查的判断过程，30 分钟到期或重启后回到常规模式。按 5 MiB 分卷，默认保留 14 天，总量最多 50 MiB。

排查时先看 `state.json`，再按 `session`、`operation`、`parentOperation` 和 `sequence` 串联请求、判断、调用、验证和重试。`previous_session_unclean` 只表示上次没有正常结束，不能单独证明崩溃。错误记录保留原始错误码和执行阶段；日志不可写会在面板提示，主要控制功能继续运行。

日志统一脱敏用户目录路径；屏幕状态只记录运行期显示器编号、内外屏类型和连接状态，不采集设备序列号、录音、屏幕内容、窗口标题、浏览记录或环境变量全集。系统防睡眠摘要仅包含断言类型与状态，不收集其他应用的完整活动详情。

## 电量读取

启动时读取一次，之后每 24 小时刷新，也可手动刷新。需要本机 Python 3 和 `hid` 包，可用 `LOGI_BATTERY_PYTHON` 指定解释器。

标准输出与错误输出非阻塞读取，各最多保留 64 KiB；单候选运行最多 10 秒，整次预算 20 秒，另给最多 3 秒终止清理。超时、退出码和解析失败都有记录。退出时取消读取，避免卡死在刷新状态。

## 构建与验证

```sh
./scripts/build_app.sh
swift test
python3 -m unittest discover -s Tests/Python -v
```

构建生成 `dist/Keep Awake.app` 和项目根目录的安装副本，进行本机临时签名。最低 macOS 13，构建使用当前 Xcode SDK；无需管理员权限或关闭 SIP。

测试覆盖设置迁移、屏幕恢复和重试、电源断言回滚、进程输出和超时、日志轮转与脱敏、诊断打包、登录项路径和单实例锁。真实拔线、睡眠唤醒、麦克风及界面外观需分别进行实机验收。
