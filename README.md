# Keep Awake

一个 macOS 菜单栏小工具，用来控制屏幕和电脑的防睡眠状态，并在状态栏图标里显示 Logitech 鼠标电量。

## 功能

- `保持屏幕亮起`：开启后屏幕不会自动熄灭，同时会自动开启防止电脑自动睡眠。
- `防止电脑自动睡眠（屏幕可熄灭）`：电脑保持唤醒，但允许屏幕按系统设置熄灭。
- `开机自动启动`：从当前 `Keep Awake.app` 写入用户级 LaunchAgent，下次登录后自动启动。
- 状态栏图标使用显示器样式，图标内显示 Logitech 电量百分比。
- Logitech 电量在启动时读取一次，之后每 24 小时刷新一次；也可以在菜单里手动点击 `刷新电池电量`。

## 构建

```sh
./scripts/build_app.sh
```

脚本会构建 release 版本，并在项目根目录生成本地可运行的 `Keep Awake.app`。构建产物不会提交到 Git。

## Logitech 电量读取

电量读取脚本位于 `Resources/check_logi_battery.py`，打包时会复制到 app bundle 的 `Contents/Resources`。运行环境需要本机可用的 `python3`，并安装 `hid` Python 包；应用会从 Python Framework、`PATH` 和常见 Homebrew 路径自动查找，也可以通过 `LOGI_BATTERY_PYTHON` 指定 Python 路径。

## 外接显示器时关闭内置屏幕

菜单新增：

- **外接显示器时自动关闭内置屏幕**：默认关闭。开启后，实体外接屏可用约 2 秒后停用内置屏幕；最后一台可用外接屏断开后优先恢复。AirPlay、Sidecar、虚拟屏和无法确认类型的屏幕不触发关闭。
- **保持内置屏幕开启**：立即恢复内置屏幕，并覆盖自动关闭规则。此选择会一直保存，直到手动关闭，包括重启 App 和重新连接外接屏。

使用时请保持笔记本开盖；Apple Silicon Mac 合盖会在硬件上切断内置麦克风。本功能不切换录音设备，不申请麦克风权限。现有“保持屏幕亮起”只针对当前启用的屏幕。

这是真正的软件停用，内置屏不再参与桌面布局，窗口可能重新排列。恢复时尝试恢复原有镜像关系（仅限相关屏幕仍连接）；不还原各窗口位置。关闭自动功能或正常退出时恢复由本功能关闭的内置屏；恢复失败会取消退出，保留菜单供重试。异常退出后，下次启动先恢复，再应用自动规则。

实现使用运行时加载的 macOS 私有 SkyLight/CoreDisplay 接口；不需要管理员权限，也不修改 SIP。接口缺失时显示不可用，不影响原有功能。实际功耗收益未经测量。屏幕配置仅应用于当前登录会话。

若恢复失败，先开启“保持内置屏幕开启”，再尝试重新开合上盖或拔插外接屏；仍无效时注销或重启。App 崩溃期间无法保证即时恢复。短时间反复关闭达到 3 次后暂停自动控制，重新开关自动功能可重试。

测试：`swift test`。屏幕控制策略通过模拟设备测试；实机关闭/恢复、镜像、拔线、唤醒和麦克风测试应分别记录，不能互相替代。
